## What the administrator can do

- **Lab CRUD** — create, edit, and delete labs (name, city, address, contact, photo).
- **Lab-manager acceptance** — approve or reject users who applied to manage a lab.
- **Manager ↔ Admin chat** — see incoming threads from managers with unread counts.
- **System Panel** — override the API base URL at runtime (`SharedPreferences` backed), read server health, tweak admin-level config.
- **System-wide visibility** — see every user, every lab, every donation across the network.
